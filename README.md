# ai-architect-learning

Interactive training track: designing governed, secure AI systems as an architect.

**Open it:** https://olekvaaga-png.github.io/ai-architect-learning/

A five-stage course for an engineer with a data technology background who wants to move into AI and cyber security, and learn to think like an architect:

| Stage | Modules |
| --- | --- |
| 0 Orientation | Think like an architect |
| 1 Security foundations | Identity and delegated access · One write path · Proving security |
| 2 Cloud and architecture | Skeleton and slots · Task functions, apps and models · Runtime and state on Azure · Hybrid cloud and placement |
| 3 Applied AI and agents | Claims, not facts · Agents as identities · Token cost · Verified data and the semantic layer |
| 4 Where AI and security meet | The model boundary · Governing agents and change · Traceability and audit |
| Capstone | Design material availability as a capability |

Each module has animated walkthroughs, exercises, reflection questions and architect scenarios with model answers. Notes and progress are kept only in the reader's own browser.

The whole course is one self-contained file, `index.html`. It needs no build step.
